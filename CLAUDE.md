Chapter 2 ("Linear Regression") is the first full algorithm, going deep on theory + math only (Varun explicitly wants theory/math first, code later as a separate follow-up step). **Notation: uses plain `y = mx + b` throughout, not $\hat{y} = \beta_0 + \beta_1x$** — Varun found the beta/hat notation unreadable on first pass, so the chapter was rewritten around the school-algebra version (with a note up top translating to $w$/$\beta$ notation for when he sees it elsewhere) and closely follows the flow of a prior conversation that actually clicked for him. Chapter 3 ("Logistic Regression") is the second full algorithm, same theory+math-only style and plain `m`/`b`/`x`/`y` notation as Chapter 2. Covers: why Logistic Regression is classification despite the name (built on Linear Regression's machinery but predicts a category); why fitting a straight line to 0/1 data breaks (out-of-range outputs, wrong S-shape); the Sigmoid function (`p = 1/(1+e^-z)`, with `z = mx+b` computed exactly as in Chapter 2) squashing any `z` into a 0-1 probability, with a full worked exam pass/fail dataset (decision boundary lands exactly at the threshold); thresholding at 0.5 to get a category; why MSE doesn't work as the cost function here (doesn't punish confident-wrongness harshly enough) and Log Loss / Binary Cross-Entropy as the fix, with worked numbers showing confident-correct (loss 0.01) vs confident-wrong (loss 4.6) vs unsure (loss 0.69); why Logistic Regression has no direct-solve formula like OLS and must use Gradient Descent; a preview mention of Multinomial/Softmax Regression for 3+ categories; assumptions (linearity of log-odds, independence, no multicollinearity, sample size per class); and a short Odds/Log-Odds side-note tying back to the "linearity of log-odds" assumption. Written to `03-Logistic Regression/theory.md`, all worked numbers (sigmoid values, log loss) verified with a script before writing.
